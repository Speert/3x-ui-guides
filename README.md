# 3X-UI Guides

Руководства по настройке и диагностике 3X-UI VPN панели

## Инструкции

### 🔧 [Проверка и решение блокировки UFW](ufw-blocking-troubleshooting.md)

Что делать, если:
- Панель 3X-UI недоступна с вашего IP
- VPN подписка не обновляется
- Новые SSH соединения не устанавливаются
- С других IP всё работает
- Через 5-10 минут всё восстанавливается

Инструкция объясняет причину (UFW rate limiting) и предлагает решения.
