# 3X-UI Guides

Руководства по настройке и диагностике 3X-UI VPN панели

## Инструкции

### 🔧 [Проверка и решение блокировки UFW](ufw-blocking-troubleshooting.md)

Что делать, если:
- Панель 3X-UI недоступна с вашего IP
- VPN подписка не обновляется
- Новые SSH соединения не устанавливаются
- С других IP всё работает
- Через 5-10 минут всё восстанавливается

Инструкция объясняет причину (UFW rate limiting) и предлагает решения.

### 🔍 [Проверка оптимального MTU для VPN](mtu-check-guide.md)

Как проверить и настроить MTU:
- Проверка с компьютера на сервер и обратно
- Метод подбора оптимального значения
- Установка MTU в разных VPN клиентах
- Рекомендации и частые ошибки

Правильный MTU устраняет фрагментацию пакетов и снижает частоту блокировок firewall.

### 📊 [Автоматический мониторинг UFW через Telegram](ufw-monitoring-telegram.md)

Настройка автоматических отчётов о безопасности сервера:
- Количество блокировок UFW
- Топ-10 заблокированных IP
- Топ-3 порта
- Статус fail2ban
- Полная инструкция по созданию бота и настройке cron

Получайте регулярные отчёты о состоянии firewall прямо в Telegram.
